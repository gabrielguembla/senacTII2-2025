# Atividade Prática: Desenvolvimento de um CRUD

## Informações da Atividade


### Objetivo

Desenvolver uma aplicação capaz de realizar as quatro operações básicas de um CRUD: 
Criar (Create), Ler (Read), Atualizar (Update) e Excluir (Delete). O principal objetivo da 
atividade é praticar a lógica de programação, a manipulação de dados e a organização 
do código utilizando JavaScript.

### Tecnologias Permitidas
Cada aluno ou dupla poderá escolher uma das seguintes abordagens:
• HTML, CSS e JavaScript
• React
A escolha da tecnologia não influenciará a nota. O foco da avaliação será a 
implementação correta das funcionalidades solicitadas.
Requisitos da Atividade

### O sistema desenvolvido deverá permitir:

• Inserir dados: o usuário deverá conseguir cadastrar informações através de um 
formulário.
• Visualizar dados: os dados cadastrados deverão ser exibidos na tela de forma 
organizada.
• Atualizar dados: o usuário deverá conseguir editar informações já cadastradas.
• Excluir dados: o usuário deverá conseguir remover registros do sistema.

### Tema

Tema livre. O mais importante é que o projeto implemente corretamente todas as 
operações de CRUD (Create, Read, Update e Delete).

### Estrutura Mínima dos Dados

Cada registro deve possuir pelo menos:
• Um identificador (id).
• Duas ou mais informações relacionadas ao tema escolhido.

### Critérios Adicionais Observados

• Organização do código
• Clareza da interface
• Boa utilização do JavaScript
• Nomenclatura adequada de variáveis e funções
• Separação de responsabilidades no código

### Desejavel

• Utilizar Local Storage para persistir os dados.
• Implementar busca ou filtro.
• Criar validações nos formulários.

### Entrega

Enviar o projeto completo contendo todos os arquivos (zipados) necessários para 
execução. O projeto deve estar funcionando e permitir demonstrar todas as operações 
do CRUD durante a apresentação ou correção.
